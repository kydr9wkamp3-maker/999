# Dataset and fixture register

No external benchmark dataset is currently bundled or approved for redistribution. A dataset name alone is not a license grant. Obtain exact terms from the dataset owner before downloading, redistributing, or publishing image-derived artifacts.

## Required register fields

| Dataset/fixture ID | Owner/source URL | Version/date | License/terms URL | Redistribution permitted? | Intended split | Local manifest path | SHA-256 manifest | Approved by/date |
|---|---|---|---|---|---|---|---|---|
| None approved yet | | | | | | | | |

## Fixture manifest format

Keep image files outside the Git repository unless size and license review approves otherwise. Store a text manifest with one record per fixture:

```text
fixture_id,source_name,source_version,license,split,width,height,format,sha256,notes
```

Do not record the user's real filename, GPS/EXIF location, face identity, device serial, or original URI. Use sanitized stable IDs. Verify no train/test leakage, especially for crops or near-duplicates.

## Suggested categories to acquire and license-check

- Natural photographs at multiple resolutions and textures.
- Screenshots/UI/text and line art.
- Synthetic gradients, checkerboards, random noise, alpha/transparency, and adversarial patterns generated by repository scripts.
- Scientific microscopy/multispectral data only with domain-specific data-use review.

For each category define source, color profile, bit depth, alpha, orientation, exact byte hash, split, and permitted redistributions. Until then, benchmark rows must state that no licensed corpus was used.
